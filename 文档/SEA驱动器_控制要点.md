## 0. 一分钟结论

1. 这两本是**硬件/接线手册**，不是软件/通讯手册。它们能回答“驱动器支持什么控制模式、怎么接线、采样多快、有哪些 IO/STO”，但不能回答“寄存器怎么配、PDO 怎么映射、增益怎么整定、回零怎么做”。
2. 对 linrot-arm 直接有用的部分：
   - 位置 / 速度 / 电流（转矩）三种控制模式；
   - 电流环、速度环、位置环均 10 kHz 采样；
   - 6 路 DI、2 或 4 路 DO，DI 可配置为使能、复位、正/负限位、停止、原点捕获；
   - 双通道 STO（选配）；
   - 编码器接口支持绝对 / 增量 / 霍尔 / Sin-Cos / 旋变；
   - EtherCAT 或 CANopen DS402，CAN 最高 1 Mbps；
   - 供电 / 连续电流 / 峰值电流表，可用于驱动器选型。
3. **关键关联判断（已确认）**：CAD 零件名显示肩部三轴是 `EC-A6013-H20-100`（×2）和 `EC-A3814-H14-107`，属于**自带驱动器的集成关节模组**（CAN 接口）。经确认，这两本 SEA 手册只覆盖**肘部 `dg4000` + 腕部 2 个直线电缸**这 3 个直线轴，不覆盖肩部 3 个关节。该对应关系由用户于 2026-11-21 确认；不要把两套完全不同的控制接口混在一起。
4. 手册**没有**给出：对象字典 / ESI / EDS、PDO 映射、CiA402 支持的模式、位置 / 速度 / 电流缩放、增益与滤波、回零流程、编码器分辨率、丝杠导程、电缸行程 / 推力、再生制动 / 制动电阻、STO 安全等级与响应时间。这些是 linrot-arm 做控制器前必须补的。
5. 项目当前 `REV_EFFORT=60 N·m`、`REV_VELOCITY=3.0 rad/s`、`SLIDE_EFFORT=200 N`、`SLIDE_VELOCITY=0.5 m/s` 都是占位值；其中 `SLIDE_EFFORT=200 N` 与 `dg4000` 的 4000 N 级推力明显不匹配，不能直接拿去做控制验证。

## 1. 与 linrot-arm 的关联

### 1.1 项目执行器盘点

| 轴 | 项目执行器 | 传动 | 控制量 | 驱动器归属 |
| :--- | :--- | :--- | :--- | :--- |
| R1 肩 1 | `EC-A6013-H20-100` | 谐波 100:1，直连法兰 | 关节角 | 模组内置驱动，CAN |
| R2 肩 2 | `EC-A6013-H20-100` | 谐波 100:1，直连法兰 | 关节角 | 模组内置驱动，CAN |
| R3 肩 3 | `EC-A3814-H14-107` | 谐波 107:1，直连法兰 | 关节角 | 模组内置驱动，CAN |
| L1 肘 | `dg4000` 直线电缸 | 四连杆闭环 `R6` | 缸长 / 推力 | SEA 驱动（已确认） |
| L2 腕右 | 腕部直线电缸 | 十字轴 + 双缸并联 `R10` | 缸长 / 推力 | SEA 驱动（已确认） |
| L3 腕左 | 腕部直线电缸 | 同上 `R12` | 缸长 / 推力 | SEA 驱动（已确认） |

> 依据：`model/mapping.json` 中的 CAD 零件名；`model/README.md` 的刚体表；`README.md` 第 1 节。

### 1.2 关键判断：SEA 手册覆盖哪几个轴

- `EC-A6013-H20-100` / `EC-A3814-H14-107` 是“减速器 + 电机 + 驱动器”一体的关节模组。公开资料给出 48 V、CAN 1 Mbps、双 14 位编码器、100:1 / 107:1、额定 40 / 20 N·m、峰值 130 / 60 N·m（**外部资料，需以 ENCOS 正式手册核对**）。
- 这类模组不需要外置 SEA 驱动器；它的控制接口是 CAN，不是 SEA 的脉冲 / ±10 V / EtherCAT。
- 因此，把这两本 SEA 手册当成“6 个轴通用”的依据是错误的。经确认，它们只覆盖 3 个直线电缸轴。
- 如果实际方案是“EC-A 只当机械本体，电机相线 / 编码器引到 SEA”，那需要拆模组、旁路内置驱动，风险和改动都很大；必须明确否认或确认。

**结论（已确认）**：SEA 驱动器只接 3 个直线电缸（肘 `dg4000` + 腕部 2 个电缸）；肩部 3 个关节走 EC-A 模组自带的 CAN 驱动。因此“6 个执行器的指令类型”应拆成两套：3 个 CAN 关节模组 + 3 个 SEA 直线轴。

### 1.3 控制架构上的位置

```text
ROS 2 / ros2_control（100–1000 Hz）
        │
        ├─ 笛卡尔位置控制器 → IK → q(6)
        │
        ├─ 机构映射 q ↔ 执行器坐标
        │     R1,R2,R3：关节角（直连）
        │     q_肘 → L1（四连杆）
        │     q_腕1,q_腕2 → L2,L3（双缸并联）
        │
        ├─ 肩部：独立 CAN → EC-A 模组（内置位置环）
        │
        └─ 直线轴：EtherCAT DS402 → SEA 驱动 → 电缸
                              │
                              └─ 驱动器位置环 10 kHz → 电流环 10 kHz
```

- 肩部：控制器发关节角，模组内置驱动器闭环。
- 直线轴：控制器发**缸长**（位置模式，本项目第一版已确认）或**推力 / 电流**（转矩模式，后期力控再考虑），SEA 驱动闭环。
- 无论哪种，控制器都要做“关节角 ↔ 缸长”的机构映射；这是 SEA 手册之外、但由 SEA 的“位置模式”直接引出的工作。

### 1.4 闭环机构带来的特殊问题

1. **肘部四连杆**：1 个电缸 → 1 个肘关节，映射是单值的。只要 `L1` 的零点和方向标定正确，位置模式可以直接用。
2. **腕部双缸并联**：2 个电缸 → 2 个腕自由度，映射是联立的。若 `L2`、`L3` 的目标不是由同一组腕关节角算出来的，两个缸会在结构内“打架”，表现为：
   - 驱动器位置误差增大，甚至触发位置误差保护；
   - 电流升高、发热；
   - 十字轴 / 推杆承受额外内力。
   因此腕部必须用**机构正 / 逆解**生成一致的目标，不能用两个独立的 PID 各自追。
3. **肩部**：3 个模组直连，关节角就是控制量，不需要机构映射；但模组的 CAN 协议、零位、限位、抱闸都要单独确认。
4. **负载编码器**：SEA 手册提供 A/B 两路反馈接口，但未说明是否支持双编码器闭环。若电缸只有电机端编码器，关节角靠机构映射推算，背隙和连杆误差会直接进入关节精度；若加负载端编码器，可把位置环闭到负载，但需要软件手册确认。

## 2. 控制模式与指令接口

### 2.1 三种控制模式

| 模式 | 指令方式 | 输入信号 | 适用场景 |
| :--- | :--- | :--- | :--- |
| 位置控制 | 脉冲、±10 V 模拟量、总线（DS402，具体模式待确认） | 方向 + 脉冲 / AB 正交 / CW-CCW；模拟 ±10 V | 直线轴正常作业；点到点定位 |
| 速度控制 | PWM、±10 V 模拟量、函数发生器、软件编程、总线（DS402，待确认） | PWM 1–100 kHz；模拟 ±10 V | 调试、匀速测试、速度环验证 |
| 电流 / 转矩控制 | PWM、±10 V 模拟量、函数发生器、软件编程、总线（DS402，待确认） | PWM 1–100 kHz；模拟 ±10 V | 力控、张力、碰撞检测；调试 |

> 手册第 3.3 节写“控制模式：位置，速度，转矩”；第 3.4 节表头写“电流控制”。两者是同一件事：给定电流环，输出转矩近似正比于电流。

### 2.2 位置控制

| 项目 | 参数 |
| :--- | :--- |
| 脉冲形态 | 方向 + 脉冲、A/B 相正交脉冲、CW/CCW 脉冲 |
| 信号格式 | 差分输入、集电极开路 |
| 最高脉冲频率 | 差分 2 Mpps；集电极开路 500 kpps |
| 模拟指令 | ±10 V，差分输入阻抗 5 kΩ |
| 其他 DI 功能 | 伺服使能、外部复位、正 / 反转限位、电机运转停止、高速模拟量采集、PWM 同步输入、高速脉冲输入 |

> 对 linrot-arm：主控制不要走脉冲 / 模拟量，走 EtherCAT 或 CANopen；脉冲 / 模拟量只用于台架调试。

### 2.3 速度 / 电流控制

| 项目 | 参数 |
| :--- | :--- |
| PWM 极性 | 0–100% + 方向位；或无极性 50%±50% |
| PWM 频率 | 1–100 kHz |
| 最小脉冲宽度 | 220 ns |
| 模拟指令 | ±10 V，差分 5 kΩ |
| 其他 | 函数发生器、软件编程（Stand-alone） |

> 台架调试建议：先用 ±10 V 模拟速度模式验证电机方向、编码器极性、限位和 STO；确认无误后再切到总线位置模式。

### 2.4 运动模式（Stand-alone / 内部）

- 电子齿轮
- 电子凸轮
- 比例联动
- 点到点（PTP）

> 这些是驱动器内部运动功能。linrot-arm 的控制层级是“上位机 IK + 关节 / 缸长目标”，不建议把轨迹规划下放到驱动器；电子齿轮可用于“电机转数 → 缸长”的缩放（需软件手册确认寄存器）。

## 3. 环路、采样与带宽

| 项目 | 参数 | 对控制的意义 |
| :--- | :--- | :--- |
| 电流环采样 | 10 kHz | 电流环带宽高，转矩响应快 |
| 速度 / 位置环采样 | 10 kHz | 驱动器内部位置环可独立稳住缸长 |
| 电流环带宽 | 约 10 kHz（随参数 / 负载电感变化） | 手册未给速度 / 位置环带宽 |
| 脉冲响应 | 最高 2 MHz，带数字滤波 | 仅脉冲指令；总线控制不用 |

- **级联结构**：上位机（100–1000 Hz）→ SEA 位置环（10 kHz）→ 电流环（10 kHz）。位置模式时，上位机不需要 10 kHz，1 kHz 甚至 500 Hz 即可。
- **转矩模式**：若上位机要在关节空间闭环，控制器需要 ≥1 kHz 的力矩更新；此时总线周期和抖动成为关键。第一版采用位置模式（2026-11-21 确认），先把机构跑通。
- **同步**：肩部 CAN 模组与 SEA 总线如果不在同一时钟域，外环要用时间戳 / 插值，避免两套执行器“各走各的”。

## 4. 反馈与编码器

### 4.1 支持的反馈类型

- 绝对式编码器（串行：BiSS / SSI / EnDAT、NRZ、Hiperface 等）
- 增量式编码器（A/B/Z，差分）
- 霍尔（Hall A/B/C）
- 模拟量正余弦（Sin/Cos 1.0 Vpp）
- 旋转变压器（Resolver）

### 4.2 接口划分

| 接口 | 0 选项 | 1 选项 | 说明 |
| :--- | :--- | :--- | :--- |
| 接口 A | 绝对式 / 增量式 / 霍尔 | 绝对式 / 增量式 / 霍尔 | 电机端反馈 |
| 接口 B | 增量式 / 模拟量 | 旋变 | 第二反馈 / 负载端（是否支持双闭环需软件手册） |
| 接口 C | 模拟编码器输出 | 模拟编码器输出 | 旋变 / 模拟编码器模拟输出 |

> 选型码中的第二位 `0/1` 决定接口 A/B 的组合；订货时要把编码器类型写进型号，不要事后改。

### 4.3 接线与抗干扰

- 编码器线 ≤1 m 可用非屏蔽线；>1 m 或强干扰环境用**屏蔽双绞线**，屏蔽层接驱动器 `COMRET`。
- 电机动力线与编码器线分开走线，避免平行长距离。
- 增量式编码器需要回零；绝对式不需要，但要多圈记忆 / 电池（视编码器而定）。
- 手册只提到“原点模式为高速模式，可用于快速捕获和精确制导”，**没有给回零流程**；需要软件手册。

### 4.4 对 linrot-arm 的影响

- 直线电缸若用增量编码器 / 霍尔，开机必须回零；`q=0` 的竖直姿态不能直接当缸零位。
- 关节角 ↔ 缸长的缩放依赖：编码器分辨率、丝杠导程、减速比、电子齿轮。手册一个都没给。
- 肩部 EC-A 模组是双 14 位编码器 + 100:1 / 107:1，输出分辨率理论上很高，但背隙（公开资料 10 arcsec 级）和连杆误差才是瓶颈。

## 5. 通信接口

| 接口 | 参数 | 用途 | 手册缺口 |
| :--- | :--- | :--- | :--- |
| EtherCAT | RJ45 IN/OUT（J8/J9） | 实时总线，多轴同步 | 无 ESI、无 PDO 映射、无周期 / 分布式时钟说明 |
| CANopen | CAN 2.0，DS402，最高 1 Mbps | 实时总线 / 调试 | 无 EDS、无对象字典、无支持模式列表 |
| RS232 | 手册写 115 KB，通常对应 115.2 kbps | 配置 / 调试（1–80 A 在 J13，140/160/40 A 在 J7） | 无协议 / 寄存器表 |
| USB 2.0 | 仅 EtherCAT 版本（1–80 A 在 J14，140/160/40 A 在 J7） | 调试 / 配置 | 手册未给协议 |
| 脉冲 | 2 Mpps 差分 / 500 kpps OC | 位置指令 | 不适合多轴同步 |
| 模拟 | ±10 V | 速度 / 转矩指令 | 适合台架，不适合总线控制 |

- **已确认的总线架构**：SEA 走 EtherCAT + DS402；肩部 EC-A 走独立 CAN。两套总线分开，避免 1 Mbps CAN 承载 6 轴；控制器用时间戳对齐两套总线。EtherCAT 侧仍需确认是否支持 CoE 和 CSP，CAN 侧需确认 EC-A 的协议 / 波特率 / 终端电阻。
- **DS402**：手册只说“兼容 CANopen DS-402”，没说支持哪些模式（PP / PV / PT / HM / CSP / CSV / CST）。对笛卡尔位置控制，最理想是 **CSP（循环同步位置）**；若只有 PP，1 kHz 下会变成“每周期一个新目标点”，轨迹可能不平滑。
- **必须向厂家要**：ESI / EDS、对象字典、PDO 映射、支持的 DS402 模式、故障码、固件版本。

### 6.3 STO（安全扭矩关闭）

- 选配：型号后缀 `S` = STO-24 V，`S1` = STO-5 V；默认**不带 STO**。
- 双通道：`STO1`、`STO2` + `STO_RET`，光隔离。
- 接线：控制器 / 安全继电器两路独立输出分别驱动 STO1 / STO2；24 V 逻辑可直接驱动，5 V 逻辑用于 5 V 系统。
- 手册只给接线图，**没有**给：
  - STO 响应时间；
  - 安全等级（SIL / PL / PFHd）；
  - 双通道一致性要求；
  - 与抱闸的时序；
  - 复位 / 重启条件。
- 对 linrot-arm（已确认 SEA 只驱动 3 个直线轴）：SEA 的 STO 只作用于这 3 个轴；肩部 EC-A 模组的 STO / 抱闸是另一套，必须单独纳入安全链。整机急停不能只切 SEA 的 STO。

### 6.4 抱闸

- DO 可配置为“抱闸控制”，但 30 mA 驱动能力不足，需外部继电器 / MOSFET。
- 抱闸时序（先抱闸后断使能、先使能后松闸）手册未给；需要软件手册 / 厂家确认。
- 肩部 EC-A 模组是否有抱闸、抱闸电压 / 电流，需查模组手册。

### 7.4 对 linrot-arm 的选型含义

- 双电源（48 V 动力 + 24 V 逻辑）能避免电机加速时逻辑掉电，建议优先。
- 再生制动 / 制动电阻手册未提；电缸快速减速或重力下放时，母线会泵升，必须确认驱动器是否有泄放通道，否则会过压保护。

### 8.2 P1（控制 / 仿真）

1. **机构映射（已确认：实时数值求解，按讲义第四部分）**
   - 广义坐标：12 个物理树关节 + 6 个鱼眼铰 = 18 个坐标，顺序为
     `R1,R2,R3,R4,L1,R5,R7,R8,L2,L2g_gy,L2g_gx,L2g_gz,R11,R9,L3,L3g_gy,L3g_gx,L3g_gz`。
     3 个 `<connect>`（`R6/R10/R12`）共 9 行，`q=0` 时秩 8；总 DOF 10 = 6 个任务自由度 + 4 个鱼眼/推杆被动自由度。
   - 腕部关节类型（2026-11-22 已确认）：电缸**杆端是鱼眼/球铰（3 个转动自由度）**，推杆**下端是销轴（单轴转动副）**。因此腕部不是“5 行转动副”，而是“杆端 3 铰 + 下端 3 行 connect”；5 行 weld 实验是错误方向。
   - 速度级：`c_q q̇ = 0`。把坐标分为独立 `q_I`（6 个执行器）和被动 `q_D`（12 个：6 个物理被动 + 6 个鱼眼），`q̇_D = -(J_D^T J_D)^-1 J_D^T J_I q̇_I`；位置级用 Newton 迭代 `q_D ← q_D - (J_D^T J_D)^-1 J_D^T c`。
   - 实现要求：固定最大迭代次数（如 20）、warm start、步长限幅、`J_D` 条件数检查；收敛失败保持上一有效值并报故障；切断铰转角用式 9.59–9.68 做 2π 解缠，避免过 ±π 跳变。
   - 数值现状（2026-11-22，模板 3 铰鱼眼版）：
     - 模型：`nbody=22, njnt=18, nq=nv=18, neq=3, nefc=9`；约束秩 8，总 DOF 10。
     - `q=0`：`E_active @ N` 秩 6；`B12` 任务 Jacobian 秩 6，奇异值 `[55.07, 28.70, 4.47, 1.15, 0.346, 0.033]`。
     - 差动 `L2=+5 mm / L3=−5 mm`：4 次迭代收敛，残差 `2.25e-16`；任务秩仍 6；被动鱼眼角都在 ±0.15 rad 内。
     - 对比：2 铰（Y-X）杆端任务秩只有 5；补上 Z 自转后恢复到 6。鱼眼必须按 3 个转动自由度建模。
   - 肘部可用行程：connect 基线从 `q=0` 起约 `+7 / −50 mm`（+8 mm 起残差增大并饱和，−60 mm 求解失败），不是占位 ±100 mm。这个数字只用于反推零位与 CAD 几何；换约束模型后必须重测，真机限位仍以电缸实际行程为准。
   - 验证：检查 `c(q)` 残差、`J_D` 最小奇异值、缸长速度限幅；全工作空间用同一套 18 坐标模型对照。

2. **腕部鱼眼模型（已确认并落地）**
   - 结构：每根腕部电缸的杆端是 3 自由度鱼眼（MJCF 用 `L2g_gy/gx/gz`、`L3g_gy/gx/gz` 三个铰近似），推杆下端是销轴（`R11` 树关节、`R12` connect 3 行）。
   - 结论：2 铰（Y-X）不够，任务秩只有 5；补上 Z 自转后任务秩 6，差动残差 2.25e-16。
   - 模型：`nbody=22, njnt=18, nq=nv=18, neq=3, nefc=9`；约束秩 8，总 DOF 10（6 任务 + 4 被动）；`sim/check_model.py` 已改成检查任务秩 6。
   - 限位：6 个鱼眼铰暂定 ±0.5 rad（`GIMBAL_LIMIT`），等鱼眼轴承型号/摆角规格确认后收紧；过大的被动角要报故障或软限位。
   - 控制器：q↔L 求解器把 6 个鱼眼铰作为被动坐标；用上一周期值 warm start，避免 3 铰欧拉顺序在极限附近跳分支。

3. **腕部一致性测试**：给定腕关节角，算 L2/L3；在仿真里加位置误差 / 内力监测，验证不会“打架”。
4. **`tool0` 腕心坐标系**：控制器以腕心为末端点，模型要加 `tool0` 和可配置偏置。
5. **碰撞体**：13 个刚体加简化碰撞体，至少覆盖大臂 / 腕部 / 电缸。
6. **IK 与工作空间 / 奇异位形**：用 MJCF 做数值 IK，扫工作空间，找奇异；`q=0` 和“腕部 common 偏置”都不能直接当非奇异 home，需要差动 / roll 偏置。
7. **SEA 驱动接口**：位置模式下的 EtherCAT / CANopen DS402 状态机、PDO/SDO、故障复位、看门狗。
8. **回零**：增量编码器轴的回零流程；原点开关 / 索引捕获。
9. **安全链**：STO、抱闸、限位、急停、通信丢失。

### 8.3 台架调试顺序（建议）

1. 单台 SEA + 单电机 / 电缸，模拟 ±10 V 速度模式：方向、编码器极性、限位、STO。
2. 位置模式小行程：确认缸长缩放、零点、软限位。
3. 总线模式：DS402 使能 / 故障复位 / 位置指令；用驱动软件 / 示波器看跟随误差。
4. 装到臂上：肩单轴 → 肘四连杆 → 腕双缸 → 全臂，先慢速再联动。
5. 笛卡尔位置控制：小范围、低速，逐步扩大工作空间。
6. 安全测试：STO、急停、断线、过压、堵转。
