# linrot-arm 运动学推导

本目录按多体系统运动学的递推方法，对 `linrot-arm` 的 **18 体派生树 + 3 个闭环**模型做完整推导：
位置、速度、加速度、任意体雅可比、闭环约束，以及这些方程在本机械臂上的具体形式。

> **范围说明**
>
> 本文只讨论运动学。目录中不含控制算法、逆解迭代、轨迹生成或电机驱动代码。
> `verify_kinematics.py` 只做正解、雅可比、加速度和闭环残差的数值校核，不是控制器。

---

## 1. 模型速览

机械臂是“直线电缸 + 旋转电机”混合驱动的 6 自由度臂。物理上有 13 个刚体 `B0..B12`，
但运动学上可以合并三个不动的刚体：

- `B0` 与 `world` 固结，并入地面；
- `B10` 与腕部左鱼眼末端体固结；
- `B11` 与腕部右鱼眼末端体固结。

合并后得到 **18 个运动体**，编号 `1..18`，并保证：

- 体 `i` 恰好由关节 `i` 驱动；
- 父体编号 `p(i) < i`；
- 每个关节只有一个广义坐标 `q_i`，所以 `q ∈ R^18`。

3 个闭环在派生树中被切断，作为 3 个 **cut joint** 处理：

| 闭环 | 父体 | 子体 | 作用 |
| :--- | :--- | :--- | :--- |
| `R6` | `B3` | `B6` | 肘部四连杆 |
| `R10` | `B7` | `B12` | 腕部十字轴第二轴 |
| `R12` | `B11` | `B12` | 腕部左推杆 |

模型文件：

- 树与关节参数：`model/mjcf/linear_arm.xml`
- 闭环锚点：`model/loops.yaml`
- 数值源：`model/templates/*.tpl`（不要手改生成物）

## 2. 主要结论

在 `q=0` 名义位形下，数值校核得到：

| 项目 | 结果 |
| :--- | :--- |
| 运动体数 | 18 |
| 树关节数 | 18 |
| 闭环约束 | 3 环 × 3 行 = 9 行 |
| 闭环雅可比 `Jc` 的秩 | **8** |
| 独立坐标数（DOF） | **10** |
| `B12` 任务雅可比的秩 | **6** |
| 约束零空间上的任务雅可比秩 | **6** |
| 内部自由度 | **4** |
| 执行器关节 | 6（`R1,R2,R3,L1,L2,L3`） |
| 被动关节 | 12 |

几个需要强调的点：

1. **9 行闭环约束的秩是 8，不是 9。**
   `R6` 是平面四连杆，`B6` 相对 `B3` 的锚点差始终落在 `B3` 的 `XZ` 平面内，
   所以 `R6` 的 3 行位置约束中有一行是结构冗余；`R6` 块秩为 2。
   `R10`、`R12` 各贡献 3 行满秩，总秩 `2+3+3=8`。

2. **总 DOF 是 10，任务 DOF 是 6，剩下 4 个是内部自由度。**
   `18 - 8 = 10`。在 `Jc` 的零空间（10 维）上，`B12` 任务雅可比仍是 6 秩，
   因此有 `10 - 6 = 4` 个不改变末端位姿的内部运动方向。

3. **6 个执行器不等于 6 个独立坐标。**
   12 个树关节是被动关节。纯运动学只能给出 10 维位形空间；
   给定 6 个执行器坐标后仍有 4 个内部自由度，需要动力学或额外约束才能确定。

4. **`q=0` 接近任务奇异。**
   约束零空间上的任务雅可比最小奇异值为 `0.01188`，虽然秩仍是 6，但已经接近奇异。
   本文只报告这个事实，不做奇异回避或控制设计。

5. **闭环必须按球铰（3 行）建模，而不是按刚性转动铰（5 行）建模。**
   若把 3 个闭环都按 5 行转动铰处理，会得到 15 行约束、秩 11、DOF 7，
   但任务雅可比在约束零空间上的秩降为 5，与“6 维任务能力”矛盾。
   本手臂的杆端是鱼眼/球铰，`connect` 的 3 行模型才与机构一致。

## 3. 符号与坐标约定

### 3.1 坐标系

- `0`：世界系（`world`）。
- `i`：体 `i` 的连体坐标系，原点为 `O_i`。
- `q=0` 时所有体坐标系与世界系同向；关节轴在模型里按世界方向书写。
- 每个体的原点取在驱动它的关节轴点上。

### 3.2 变换与位置

| 符号 | 含义 |
| :--- | :--- |
| `A_{i,j}` | 把 `j` 系向量变换到 `i` 系的旋转矩阵：`v|_i = A_{i,j} v|_j` |
| `A_{i,j} = A_{j,i}^T` | 正交矩阵的逆等于转置 |
| `r_{P_1P_2|i}` | 从点 `P_1` 指向 `P_2` 的矢量在 `i` 系中的投影 |
| `r_i` | `r_{O_0O_i|0}`，体 `i` 原点在世界系中的位置 |
| `o_i` | 关节 `i` 的轴点相对父体原点的位置，在父体系中表示 |
| `n_i` | 关节 `i` 的单位轴，在父体系中表示 |
| `s_i` | 棱柱铰的滑移量：转动铰 `s_i=0`，棱柱铰 `s_i=n_i q_i` |
| `p(i)` | 体 `i` 的父体编号 |
| `pvec[i]` | 体 `i` 的前序集合（含 `i` 自身） |

### 3.3 速度、加速度与约束

| 符号 | 含义 |
| :--- | :--- |
| `v_{i,j\|j}` | 体 `j` 相对体 `i` 的 6 维速度，投影在 `j` 系 |
| `v_i` | `v_{0,i\|i}`，体 `i` 的绝对速度 |
| `a_{i,j\|j}` | 体 `j` 相对体 `i` 的 6 维加速度，投影在 `j` 系 |
| `a_i` | `a_{0,i\|i}`，体 `i` 的绝对加速度 |
| `[a]_\times` | 叉乘矩阵，`[a]_\times b = a × b` |
| `C_{i,k}` | 把 `k` 系 6 维速度变换到 `i` 系的 6×6 矩阵 |
| `\Phi_i` | 关节 `i` 的相对速度基，6×1 |
| `\xi_i` | 关节 `i` 的相对加速度偏置，6×1 |
| `\eta_i` | 体 `i` 加速度递推的偏置项，6×1 |
| `b_i` | `qdd=0` 时的体加速度偏置，6×1 |
| `J_i` | 体 `i` 的 6×18 体雅可比 |
| `J_c` | 闭环约束雅可比，9×18 |
| `J_T` | 任务雅可比，6×18 |
| `c` | 闭环位置残差，9×1 |
| `b_c` | 闭环加速度偏置，9×1 |
| `N_c` | `J_c` 的零空间基，18×10 |

### 3.4 6 维矢量的顺序

本文统一采用

$$
v = \begin{bmatrix} v_{\text{线}} \\ v_{\text{角}} \end{bmatrix}
= \begin{bmatrix} v_x & v_y & v_z & \omega_x & \omega_y & \omega_z \end{bmatrix}^T .
$$

这与讲义一致，但与 MuJoCo 的 `mj_objectVelocity` 的顺序/坐标系约定不同。
数值校核时不要用 `mj_objectVelocity` 对照，应该用 `mj_jac @ qvel`。

## 5. 复现

在 WSL 的 `robot` 环境中运行：

```bash
cd /home/wjgzx/Projects/linrot-arm
/home/wjgzx/miniforge3/envs/robot/bin/python docs/kinematics/verify_kinematics.py --table
```

也可以使用任意装有 `numpy` 和 `mujoco` 的 Python：

```bash
python docs/kinematics/verify_kinematics.py --table
```

脚本会：

1. 解析 `model/mjcf/linear_arm.xml`，得到 18 体树；
2. 解析 `model/loops.yaml`，得到 3 个闭环的锚点；
3. 按本文的递推公式计算 FK、速度、加速度、`Jc`、`J_T`；
4. 用有限差分和 MuJoCo 做对照；
5. 输出 `OK`/`FAIL`，末行给出 `总结论: PASS` 或 `FAIL`。

最新一次运行的全部 15 项校核均为 `OK`，总结论为 `PASS`。

## 7. 边界与后续

本文给出的是**理想刚性多体运动学**：

- 刚体、理想关节、无间隙、无摩擦；
- 杆端按球铰/鱼眼处理；
- 几何取 CAD 名义值；
- 不包含碰撞、柔性、传动误差和电机动力学。

在这个范围内，10 维位形空间、6 维任务映射和 4 个内部自由度是完整的运动学结论。
控制、逆解、轨迹和奇异回避都不在本文范围内。
