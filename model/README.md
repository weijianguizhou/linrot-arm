# model —— 13 刚体 URDF / MJCF

与 `docs/手臂动力学模型.png` 完全对应的模型。13 刚体（`B0..B12`）、
12 个树关节 + 3 个闭环关节，`q=0` 为零位竖直姿态。

模型目录还包含 `build/data/`（重建源数据）、`cad/`（SolidWorks 源件）、
`docs/`（参考图与零件表）。

## 1. 坐标约定

| 项目 | 约定 |
| :--- | :--- |
| URDF 根 `base_link` / `B0` 帧 | 位于 **B0 的关节轴点**，不是 CAD 全局原点 |
| CAD → URDF | 减去 `mapping.json["B0"]["origin_mm"]` |
| 长度单位 | `urdf/linear_arm.urdf` 与 `meshes/*.stl` 均为 **米**（`meshes/.in_meters` 为哨兵） |
| link 姿态 | `q=0` 时所有 link 帧与世界系同向，关节 `rpy` 全为 0，`origin` 只是平移 |
| 网格 | 已按**世界姿态烘焙并平移到各自 link 帧**，`<mesh>` 不需要 `scale` / `origin` |
| 关节轴 | `axis` 是**世界方向**（`q=0` 时 link 帧与世界同向） |

每个 link 的原点就是**驱动它的那个关节的轴点**，所以关节 `origin` 是相邻两个轴点的差。

三条肩轴值得注意的是**不是正交的**：电机 1 的轴绕 Z 偏了 7.5°（`sin 7.5° = 0.130526`），
电机 2 的轴与它垂直、同样偏 7.5°。这是 CAD 里肩部电机堆叠的真实姿态，网格也按这个姿态烘焙，
所以不能图省事写成 `[0,1,0]` / `[1,0,0]`。

## 4. 闭环关节

URDF 是树，闭环在 `loops.yaml` 里描述、在 MJCF 里用 `<equality><connect>` 实现。

| 关节 | 父 → 子 | 站位 (mm) | 轴 | 作用 |
| :--- | :--- | :--- | :--- | :--- |
| `R6` | `B3 → B6` | `[-75.898, 137.015, -381.388]` | `[0, -1, 0]` | 肘部主铰链，与 `R4-L1-R5` 构成四连杆 |
| `R10` | `B7 → B12` | `[-49.116, 137.015, -653.388]` | `[0, -1, 0]` | 腕十字轴第二轴 |
| `R12` | `B11 → B12` | `[-89.116, 101.015, -653.388]` | `[0, -1, 0]` | 左推杆下端铰点 |

`q=0` 时三个锚点残差 0.000 mm；约束 Jacobian 秩为 6，有效自由度 6。

当前结论：

- URDF `nbody=13 njnt=12`；MJCF `nbody=14 njnt=12 neq=3`
- 整机包围盒 `137 × 202 × 767 mm`
- 总质量 `6.3624 kg`（MuJoCo 里 B0 被 `fusestatic` 并入 world，故 body 合计 5.7224 kg）
- FK 与 CAD 最大偏差 `0.013 mm`，闭环残差 `0.0004 mm`
- 惯量全部正定并满足三角不等式，所有质心落在自身网格包围盒内

## 7. 已知限制

- **没有 `<limit>`**，关节在 MuJoCo 里是无界的。等型号手册确认行程后补。
- **没有 `armature`**，质量矩阵条件数 3.1e6，直接做动力学仿真会飘。
- **没有 actuator**，`view.py` 因此默认关重力。
- **没有碰撞体**，`geom contype=0`，不做碰撞检测。
