# 直线模组手臂 · 照片构型版（linear_arm_v2_photo）

**这是按 `手臂动力学模型.png` 重排的版本，不是 CAD 实物。**

`linear_arm_v2/` 是忠实还原 SolidWorks 装配的版本；这一份是为了让预览图和
动力学模型那张图一致，把腕部重新摆过：

```
B5 前臂/腕部支架   —— 不动（和照片一致）
B6 十字轴          —— 水平销，卡在两模组顶端之间
B7/B8 腕部模组     —— 竖直，轴线平行于腕部支架（原来是横躺）
B9/B10 活塞杆      —— 从模组下端竖直伸出
B11 端板           —— 挂在两根杆末端，水平
```

## 为什么需要单独一版

CAD 里那套件**做不出**照片这个构型。越算越确认：

| 解法 | θ=−90° | θ=+90° | θ=0 |
| --- | --- | --- | --- |
| 解析闭环（端板 6 自由度 + 两杆行程） | 152.7 mm | 228.9 mm | 0.00 |
| MuJoCo 反解（放开 L2/L3 + R10） | 572 mm | 519 mm | 0.00 |
| 再放开十字轴 R6 | 572 mm | 519 mm | 0.00 |

（θ = 腕部模组绕 R7/R8 公共轴的转角；0 就是 CAD 那个姿态。表里是闭环残差。）

SolidWorks 里也配不出来，所以照片大概率对应改版前的腕部（零件名里
`part56_腕部主支架 -改`、`part4_肘部主支架 -改`、`改new_linear4000_link`）。

## 保留了什么、改了什么

| | |
| --- | --- |
| 保留 | 质量 / 质心 / 惯量张量（全部来自 CAD `GetMassProperties2`）、网格、12 刚体拓扑、关节类型、闭环断点 |
| 改 | 腕部 6 个刚体（B6..B11）在 q=0 的位置与朝向；R6/R7/R8/L2/L3/R10 的 origin 与 axis 由此反解 |
| 没改 | B0..B5 完全没动 |

因为刚体没变、只是摆放变了，**质量特性和 CAD 一致**，只有运动学的零位不同。

## 怎么调（第二版：位置全由贴合条件算，不手填坐标）

`../linear_arm_v2/tools_build_photo_variant.py` 顶部：

```python
GAP_TOP   = -0.004   # 模组顶端插进支架下沿 4 mm
PROTRUDE  =  0.015   # 零位时活塞杆露出模组的长度（=15 mm，基本收回）
PLATE_IN  =  0.005   # 端板与杆端头的搭接量
Y_PITCH   =  0.005   # 两列模组之间的间隙
# 模组 x 位置 = 支架中心线正下方（不是挂在支架前面）
```

这些不是随便填的坐标，而是**咬合量**：脚本从 B5 支架的实测包围盒出发，
把模组/杆/端板一个个按这些咬合量摆上去，所以零件之间是真的碰在一起的。

**但这些咬合量是"我给"的，不是 CAD 里真实的配合值**——照片那个布置在 CAD 里
没有对应的安装面（这也是 SolidWorks 配合不出来的原因）。要真配合，
得在支架上加对应的安装孔/面。

## 自检

```
python -c "import mujoco; m=mujoco.MjModel.from_xml_path('urdf/linear_arm_photo.urdf'); \
print(m.nbody, m.njnt, m.body_mass.sum())"
```

实测：`12 11 4.9497`（含基座 B0 时 5.6546 kg），包围盒 121 × 199 × 932 mm，
12 个刚体惯量全部正定。

## 已知差异（相对照片）

1. 现在这套件没有照片里那个"模组顶端杆端 + 横销"的实体连接件，
   R7/R8 的站位是我按模组上端面给的；
2. 端板相对两根杆的位置是按"杆端齐平"放的，照片里端板还带一点倾角；
3. 照片里腕部组占整条手臂的比例略大，说明真实模组可能更长——
   如果能量一下实物行程，把 `MOD_L` 改掉重跑会更准。
